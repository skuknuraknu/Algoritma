## 🚀 Memulai

### Prerequisites

```bash
# Go 1.21 atau lebih tinggi
go version

# Java JDK 8 atau lebih tinggi
java -version
```

### Clone Repository

```bash
git clone https://github.com/skuknuraknu/Algoritma.git
cd "Data Structures"
```

### Menjalankan Program

#### Go Programs
```bash
# Menjalankan semua file dalam folder
cd Medium
go run .

# Atau menjalankan file spesifik
go run container_with_most_water.go
```

#### Java Programs
```bash
# Compile dan jalankan
cd Arrays
javac TwoSum.java
java TwoSum
```
